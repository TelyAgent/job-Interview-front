高级后端工程师

公司：澄星协作科技（虚构测试公司）
团队：平台研发部
工作地点：上海，支持每周两天远程办公
雇佣类型：全职

岗位背景
我们正在开发面向企业的招聘协作平台，支持职位管理、候选人材料解析、面试流程及评估记录。平台需要保证不同企业的数据隔离，并为文件处理和 AI 解析提供可靠的异步任务机制。

岗位职责
1. 使用 TypeScript 和 NestJS 设计、开发和维护 REST API，与 React 前端协作完成业务功能。
2. 设计 PostgreSQL 数据模型、索引和数据库迁移，处理事务一致性、并发更新和查询性能问题。
3. 实现 PDF、DOCX、TXT 材料上传、文字提取、异步处理及失败重试，保留材料来源与版本。
4. 接入大语言模型服务，实现结构化输出校验、调用超时、错误分类和用量记录。
5. 建设项目级与租户级访问控制、操作审计，避免候选人资料被越权读取。
6. 为关键流程编写集成测试，参与故障排查、代码评审和生产服务维护。

必备要求
1. 至少四年后端开发经验，其中至少两年实际使用 TypeScript 和 Node.js。
2. 具有 NestJS 或类似服务端框架的项目经验，能够解释模块划分、依赖注入及接口参数校验。
3. 熟悉 PostgreSQL，具有索引优化、事务和数据库迁移的实践经验。
4. 有异步任务处理经验，能够说明幂等、重试、并发消费以及进程中断后的恢复方案。
5. 能独立完成 API 开发和自动化测试，并清楚说明自己在项目中的职责与技术决策。
6. 能阅读英文技术文档，并使用中文清楚沟通技术方案。

加分项
1. 实际接入过大语言模型 API，处理过结构化输出和不可信文档内容。
2. 参与过多租户 SaaS 的授权设计或越权问题排查。
3. 有文件解析、OCR 或文档处理管线的开发经验。
4. 有 Docker 部署、日志追踪或服务监控经验。

面试希望进一步了解的内容
1. 候选人如何设计避免重复创建项目的接口。
2. AI 请求已发出但任务进程重启时，如何处理重试及结果落库。
3. 多租户系统中，如何验证文件、项目和后台任务均受权限约束。
4. 性能改进的数据来自什么测量方式，候选人本人承担了哪些工作。
